# Changelog

What changes in each version of Vinus Arcade. Versions follow [semantic versioning](https://semver.org).

## 0.1.0 (2026-11-12)

The first version.

- **Blip**, the first game: one button to fly an agent between the bookshelves of an office at
  dusk.
- **Your office**: your Orca projects hang on the wall with their own icons, and your running
  agents sit at the desks, typing, waiting for you, stuck or asleep after finishing.
- **The x2 tile**: found in a run now and then, it makes the coins you catch count double for 12
  seconds.
- **Your agents in the run**: an agent that finishes mid-run sends its project into the run to be
  caught.
- **Notices in the game's own voice** when an agent finishes or needs you, with one click to go
  to it.
- **Characters and accessories** bought with the coins of your runs, shared by every game.
- **Options**: sound, hiding project names, and whether the game pauses when an agent needs you
  or finishes.
- English and Spanish.
